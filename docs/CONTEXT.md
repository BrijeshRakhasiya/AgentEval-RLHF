# AgentEval-RLHF: Project Context & Domain Specification

## 1. Executive Summary & Core Objective
`AgentEval-RLHF` is an enterprise-ready, open-source AI Agent Evaluation & Reinforcement Learning from Human Feedback (RLHF) Data Pipeline Engine. Built to replicate frontier AI data platforms (such as Micro1, Scale AI, and RLHF labs), this system executes multi-step LLM reasoning traces, subjects outputs to dual deterministic and qualitative evaluations, enables human expert interventions, and exports fine-tuning artifacts (`SFT` and `DPO` pairs).

## 2. Industry Problem Statement & Business Alignment
Frontier LLM development is shifting from static benchmark testing to dynamic, environment-based evaluation. Current industry bottlenecks include:
- **Brittle Auto-evaluators:** Pure LLM-as-a-Judge systems suffer from self-preference bias, verbosity bias, and non-deterministic logic failures.
- **Data Curation Overhead:** Bridging raw model failure logs to standardized DPO/SFT training pairs requires fragmented, manual engineering.
- **Sandbox Risks:** Executing code generated by LLM agents poses severe execution hazards without strictly isolated containerized environments.

`AgentEval-RLHF` addresses these gaps by combining subprocess/Docker sandbox execution with multi-critique LLM judging and a unified Human-in-the-Loop (HITL) curation dashboard.

## 3. Scope & System Boundaries

### In-Scope
1. **Agent Trajectory Capture:** Ingests user prompts, system prompts, tool execution logs, and final generated code/text from LLMs.
2. **Deterministic Evaluation Engine:** Runs Python unit tests and C++ gtest outputs in isolated subprocesses with timeout and memory constraints.
3. **Qualitative Evaluation Engine (LLM-as-a-Judge):** Configurable scoring rubrics (Correctness, Safety, Conciseness) returning structured JSON output.
4. **Human-in-the-Loop (HITL) Curation:** Streamlit dashboard allowing human annotators to accept, reject, or rewrite trajectories.
5. **Data Exporter:** Native formatting into Hugging Face / OpenAI compatible `.jsonl` files for Supervised Fine-Tuning (SFT) and Direct Preference Optimization (DPO).

### Out-of-Scope (v1.0)
- Distributed GPU training execution directly inside the web engine.
- Direct multi-tenant SaaS authentication (delegated to v2.0 roadmap).

## 4. Key Performance Indicators (KPIs) & Target Metrics
- **Subprocess Execution Latency:** < 2.0s per test execution suite.
- **Judge Scoring Parse Rate:** > 99% JSON schema adherence from LLM Judge response.
- **Data Export Throughput:** Real-time stream to `.jsonl` with zero memory leaks.
